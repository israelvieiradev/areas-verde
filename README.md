# ÁREAS VERDE

Objetivo

Mapeamento de áreas verde em Joinville para recriação

# Descrição

Menu interativo para cadastro, consulta e exclusão de áreas verde

# Considerações

Foram considerados validações de erros de digitação e valores incorretos, mas em alguns casos não encontrei uma
solução lógica para opção de repetição de cadastro caso valores inválidos em alguns valores.
